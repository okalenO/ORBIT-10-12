# ORBIT 10:12 主线终幕灰盒 V1

直接打开 `index.html` 即可测试。横屏 16:9 显示最佳。

## 已实现

- 以 1920×1080 为设计坐标，在 100% 浏览器缩放下自动等比适配可用窗口。
- Beach 2 黑场承接、三套服装状态继承、循环海浪声与低音量、非循环的 `singing.mp3`。
- 海边淡入后先停约 2 秒，再播放 singing；演唱结束前仅人物轻晃和飞鸟活动，互动元素保持静止且不可点击。
- 演唱结束后开放海螺、螃蟹、海星、漂流瓶互动；四个元素按“海滩整体reference.png”换算到 1920×1080 坐标，并使用不同的独立晃动周期。悬停反馈为白色描边。
- 点击 4 个不同热点或 8 秒无操作触发第四面墙段落。开头两句自动连播，来回对话只需点击一次“对话”，长段独白仍由“继续”逐句推进。
- 长对话结束后缓慢播放 `thinking.mp4`、淡回海边并切换站立人物；摸头手势提示玩家点击人物后才进入回家对白。
- 23:30 回家声音转场、右下角 SKIP、卧室淡入。
- 卧室人物按上一版的 80% 显示并站在行李箱前，入场增加挤压变形的 Q 弹效果；蛋糕、贺卡、拍立得、饮品按家具位置重排并带白边，均可点击轻晃但不推进剧情。
- 若独立灰盒读不到前序数据，四个纪念物会显示带 `data-integration-slot` 的占位素材；代码注释已标明正式整合时对应的状态字段。
- 进入卧室 5 秒未点击人物时显示兼容性更好的摸头手势；点击人物后前两句自动连播，停顿、切入 CG1，再以居中单行文字继续后续对白。
- 时间熄灭节奏延长；生日歌结束后先出现“我也同样谢谢你”，再显示“现在换我来给你拍一张照吧。”并进入终幕 MP4。
- 海边长对话结束后播放 `thinking.mp4`，随后回到海边背景并切换站立人物。
- 23:40 / 23:55 / 时间熄灭 / CG1 / 八音盒完整播放 / MP4 / 00:00 终幕流程。
- 终幕视频画面与音轨分离：约 11.9 秒、画面完全转黑后显示生日文字；回应后视频停止解码但音轨继续播放。
- 回到 CG1 显示最终文字后，由玩家点击任意空白处进入尾声。
- 独立尾声界面、纪念卡下载、制作者来信入口、AI 工具小字署名。
- 中文、韩文、英文三语文本；本场不提供语言切换，自动继承前序语言。

## 前序状态键

灰盒会优先读取这些 `localStorage` 字段：

- 服装：`orbit:selectedOutfit`（`cuteez` / `plaid` / `striped`）
- 饮品：`orbit:drinkId`
- 蛋糕：`orbit:cakeConfig`
- 贺卡：`orbit:card` 或 `orbit:greetingCard`
- 拍立得：`orbit:beachPhoto`
- 语言：`orbit:language`（`zh` / `ko` / `en`）

也可以用地址参数测试：`index.html?outfit=cuteez&lang=ko`。

## 已接入的终幕素材

- `thinking.mp4`：海边思考段（已从 HEVC 转为兼容性更好的 H.264）

- `cg-1.png`、`cg-2.png`：卧室终幕 CG

## 测试提示

- 浏览器可能阻止无手势自动播放。若右上角出现“点击画面开启声音”，点击任意位置即可。
- 为快速触发主线，请各点击一次四个不同的海边热点；重复点击同一热点不会累计。也可在演唱结束后停留 8 秒不操作。
- 对白不会自动跳过，必须使用底部按钮推进。
