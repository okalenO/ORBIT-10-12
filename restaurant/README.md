# ORBIT 10.12｜餐厅场景

该场景已经接入 ORBIT-10-12 主游戏，在街景尽头点击餐厅后进入。语言、声音和返回街景状态由主游戏统一管理；本目录仍可用于单独预览餐厅流程。

## 运行

直接打开 `index.html` 即可。也可以在本目录启动本地服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 当前流程

1. 12:00 / 餐厅占位页转场，沿用“主菜单 → 卧室”的时间与地点版式，不再播放转场影片。
2. 背景1：点击底部“对话”。
3. 字幕结束后切换背景2并显示“太害羞了”，随后先切换背景3，再显示“我们点菜吧”。
4. 点击桌面菜单，弹出三语点餐菜单；点击菜品会绘制绿色手绘圈。
5. 选择完成后菜品在桌面下方弹出并进行无文字动态提示；玩家点击食物后才会消失并进入两句人物对话。
6. 切换空景，服务员从左侧进入并询问是否准备蛋糕。
7. 点击“准备蛋糕”，可以拖动装饰到蛋糕或小熊头顶吸附点；点击裱花袋会播放沿蛋糕下缘移动一圈、奶油花边逐步出现的动画。
8. 蛋糕确认后点击桌面贺卡，输入任意祝福语与署名并保存。
9. 服务员再次从左侧进入、带着蛋糕从左侧离开；人物返回后点击“走吧”进入下一幕占位页。

## 三语

右上角按钮依次切换中文、韩语、英语。菜名、剧情文字、贺卡标签和操作按钮都会同步切换。左上角为时间、BGM 开关和返回按钮。

## 本地保留的数据

玩家确认的蛋糕装饰位置、裱花状态和贺卡原文会保存在当前浏览器的 `localStorage` 中，不上传、不审查，也不会因切换场景而丢失：

- `orbit:restaurantCakeDesign`
- `orbit:restaurantCard`

整合主项目时，也可以从 `window.ORBIT_RESTAURANT_RESULT` 读取当前点餐、蛋糕和贺卡结果。
